# Customer Behaviour Analysis

## Project Overview

This project analyzes customer shopping behaviour to identify
purchasing patterns, customer preferences, and business insights.

The analysis uses Python, SQL, Pandas, and Power BI to transform
raw customer data into meaningful insights that can support
data-driven business decisions.

## Objectives

- Understand customer purchasing patterns
- Analyze customer preferences and spending behaviour
- Identify trends across customer segments
- Generate actionable business insights
- Visualize key findings through an interactive dashboard

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Power BI
- Data Cleaning
- Exploratory Data Analysis (EDA)

## Project Structure

- data/ – Dataset used for analysis
- python/ – Python data cleaning and EDA
- sql/ – SQL queries and business analysis
- dashboard/ – Power BI dashboard
- images/ – Dashboard screenshots
- ppt/ – Project presentation

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL-Based Analysis
5. Dashboard Development
6. Business Insights
